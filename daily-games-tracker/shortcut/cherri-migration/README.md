# Experimental Cherri migration

This demo includes credential-free source experiments and a local preparation/inspection harness for an eventual Apple Shortcut implementation. It is not a complete working Shortcut.

The candidate compiler, toolchain and immutable source commit are recorded in `toolchain.lock.json`; their presence does not establish a tested build. Run the harness with `--prepare` to generate the exact Safari capture embedding. `--check` requires an independently verified local compiler. No compiler is downloaded by the harness.

The GitHub Actions workflow builds the credential-free alert probe twice and compiles the Share Sheet, Safari binding, exact capture, and JSON/Import Question probes with signing skipped when their sources, inspector, or workflow change on `main`; it also supports manual runs. It structurally inspects unsigned outputs and publishes a one-day artifact. The two alert builds differed in the order of default input-content metadata. Probes 01–04 compile and pass their current structural checks. Probe 05 exposed Cherri's literal-only JSON body parser, so it now tests custom native-variable action parameters for placing a nested dictionary into a request body. That compile and plist inspection are pending. None of the probes has been signed, installed, or executed on iPhone. The workflow does not contact WHT or use repository secrets. `--sign` remains intentionally unavailable. See `source/EXPERIMENTS.md` for limitations.
