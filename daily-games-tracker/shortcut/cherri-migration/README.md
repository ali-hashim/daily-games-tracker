# Experimental Cherri migration

This demo includes credential-free source experiments and a local preparation/inspection harness for an eventual Apple Shortcut implementation. It is not a complete working Shortcut.

The candidate compiler, toolchain and immutable source commit are recorded in `toolchain.lock.json`; their presence does not establish a tested build. Run the harness with `--prepare` to generate the exact Safari capture embedding. `--check` requires an independently verified local compiler. No compiler is downloaded by the harness.

The GitHub Actions workflow builds the credential-free alert probe twice and compiles the Share Sheet, Safari binding, exact capture, and JSON/Import Question probes with signing skipped when their sources, inspector, or workflow change on `main`; it also supports manual runs. It structurally inspects unsigned outputs and publishes a one-day artifact. The two alert builds differed in the order of default input-content metadata. Probes 01–05 compiled and passed their current structural checks in run 10. Probe 05 verifies that Cherri emits numeric version data, a native variable attachment for the assembled JSON body, and a native action-output attachment for the nested capture; actual iPhone JSON serialization remains unproven. None of the probes has been signed, installed, or executed on iPhone. The workflow does not contact WHT or use repository secrets. `--sign` remains intentionally unavailable. See `source/EXPERIMENTS.md` for limitations.
